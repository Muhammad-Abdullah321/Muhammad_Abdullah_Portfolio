# Abdullah's Portfolio

A responsive, full-screen React portfolio inspired by cinematic portfolio
layouts. Built with Vite, native CSS scroll snapping, and lightweight React
interactions.

## Get started

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it with
`npm run preview`.

## Make it yours

- Update the intro, biography, skills, project cards, and timeline in
  `src/App.jsx`.
- Replace `portfolioEmail` with your email address. The contact form opens a
  pre-filled email in the visitor's default mail app; it does not send or store
  form data itself.
- Replace the GitHub and LinkedIn links in the contact section.
- Update the page title and description in `index.html`.
- The hero portrait and project artwork are CSS illustrations, so no image
  assets are required. You can replace these with your own images.

## Sections

The portfolio has six full-screen, snap-scrolling sections: Home, About,
Skills, Projects, Journey, and Contact. Use the top navigation, numbered side
navigation, keyboard, mouse wheel, or touch scrolling to move between them.

The layout adapts for mobile and respects the visitor's reduced-motion
preference.
